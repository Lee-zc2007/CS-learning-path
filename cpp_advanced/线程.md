#线程
进程是一个程序的执行过程，进程之间相互独立，每个进程有自己的栈，堆，存储以及数据，操作系统为每个进程分配一个进程控制块PCB来管理进程
线程是一个进行中的程序执行过程，系统为每个线程分配一个栈和线程控制块，线程之间共享全局和堆的数据，每个线程有自己的栈数据

<thread>
'thread(F&& f, Args&&... args);'
用于创建线程，第一个参数是线程的入口函数（可调用对象）
是可调用对象时，Args是传递的实参
是类的非静态成员函数，Args第一个参数是用用调用这个成员函数的类对象地址（this指针），剩余参数是实参

线程中，线程函数f的返回值会被忽略，要获得返回值需要使用按引用传递的参数，也可以将返回值存储在类对象的数据成员中
'''
//这是一个函数对象类
class myfunctor{
    void operator()(double param1, double param2){
        result = param1 + param2;
    }
    double result=0;
};
'''
这里的类对象的数据成员可以保存现场线程的返回值

线程的引用参数需要用std::ref包装
'std::thread thread1(myfunc,a,b,std::ref(result));'

类似的，如果直接传入函数对象，那么会产生对函数对象的拷贝，不会直接修改原函数对象


**join**
t.join()//等待线程结束并回收资源

代码执行过程中进入等待的状态叫阻塞

当thread对象t还管理着这个子线程，t知道这个线程是谁，可以join()，也可以获取线程id，结束后由join完成资源回收

调用join的时候线程对象的状态必须是joinable

t.joinable()可以判断函数是否是可合并的

以下情况不可合并:
    默认构造函数初始化的线程对象
    join()完成的线程对象
    detach()后的线程对象
    被移动的线程对象（不再有可执行的线程）

**detach**
detach则是让t放弃对子线程的管理，让它自己运行直到结束


**get_id**
get_id可以用来获取线程id
this_thread::get_id()//获取当前执行的线程的id
t.get_id()//获取t管理的线程的id

*多个线程的使用*
先使用循环创建多个线程，然后循环join，完成时间取决于耗时最多的线程
cout的插入运算符重载函数没有针对多线程做同步措施，输出会混乱
可以用printf替换cout，printf是线程安全的
