#并行编程
并行是并发的子集（并行在不同核上，并发会分配时间片）
并行可以通过多线程实现，也可以使用工具库来实现

*OpenMP*
使用#pragma预处理指令就可以把代码转变为并行代码

'''
#pragma omp parallel for reduction(+ : sum)
    for (long i = 0; i < num_steps; i++)
    {
        double x = (i+0.5) * step;
        sum += 4.0 / (1.0 + x * x);
    }
'''
omp parallel for表示将for循环里的每次循环转为并行计算
reduction表示用于reduce计算的变量和运算符

x是局部变量，每个线程中互不干扰
sum+则是一个reduce操作，不能在并行线程中修改，否则会导致数据竞争

让omp生效需要修改编译器参数，gcc中只要添加编译参数-fopenmp

*STL并行算法库*
<algorithm>中一些函数增加了支持并行计算的重载函数
<numeric>中有一些新增的函数

形如
'std::algorithm_name(policy, /*normal args...*/)'
这些函数的第一个参数是策略类型，共有三种：
std::execution::sequenced_policy            (seq)
std::execution::parallel_policy             (par)
std::execution::parallel_unsequenced_policy (par_unseq)
小括号是对应的实例，调用时需传入

seq顺序执行，par多线程并行策略，par_unseq多线程加向量化策略（如利用硬件的SIMD功能，将同一个指令用于多个数据进行并行计算）
使用这几个策略时候需要包含<execution>

使用并行函数涉及到对共享数据的修改的时候需要程序员保证线程的同步

对于使用并行策略的有reduce运算的函数，用于reduce的操作需要满足结合律和交换率

c++标准里只规定了这些并行函数的接口和功能，没有对性能提出要求

gcc的并行算法需要OpenMP和英特尔TBB的支持
